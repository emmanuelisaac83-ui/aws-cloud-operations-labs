# Amazon Bedrock — Foundation Model Playground

## Objective

Explore foundation models using the Amazon Bedrock playground and gain practical exposure to AWS generative AI capabilities.

## AWS Service

- Amazon Bedrock

## Implementation

During this lab, I accessed the Amazon Bedrock playground and interacted with a foundation model.

The exercise introduced me to the process of submitting prompts and examining model-generated responses through the AWS Console.

## Key Learnings

- Familiarity with the Amazon Bedrock playground.
- Introduction to foundation models and prompt-based interactions.
- Understanding how AWS provides access to generative AI capabilities.
- Awareness of model access permissions, usage costs, and responsible AI considerations.

## Practical Applications

Foundation models can support use cases such as:

- Text summarization.
- Question answering.
- Content drafting.
- Information extraction.
- AI-assisted application development.

These are examples of potential applications, not claims that each use case was implemented during this lab.
